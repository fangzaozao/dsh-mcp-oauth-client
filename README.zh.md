# dsh-mcp-oauth-client 中文说明

本插件的完整中文说明请参阅 [README.md](./README.md)。

本插件适用于 DeepSeek Harness（DSH）开发者预览版，提供通用 MCP 管理界面，支持 Streamable HTTP、OAuth 2.1 + PKCE、Bearer 令牌、自定义请求头和 stdio MCP 服务。

使用前请阅读 [DSH 官方中文 README](https://github.com/deepseek-ai/deepseek-harness/blob/master/README.zh.md) 和 [安全说明](https://github.com/deepseek-ai/deepseek-harness/blob/master/SECURITY.md)。

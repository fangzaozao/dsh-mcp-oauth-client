# Changelog

## 0.3.0 - 2026-09-02

- Add a visual MCP management page for DSH Web.
- Support Streamable HTTP with no auth, OAuth 2.1 + PKCE, Bearer tokens, and custom headers.
- Support local stdio MCP servers.
- Add server creation, deletion, enable/disable, reconnect, and live tool counts.
- Add a Schemastery `Config` export and TypeScript declarations.
- Make the published bundle manager-only so it contains no private endpoint or credentials.
- Add Git-install preparation checks, release documentation, security guidance, and an MIT license.
